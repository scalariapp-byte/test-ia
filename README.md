# Vesper — Les fragments de l’aube

Un petit jeu d’arcade cosmique jouable dans le navigateur, sans dépendance ni installation.

## Lancer le jeu

Ouvre `index.html` dans un navigateur, ou démarre un serveur local depuis ce dossier :

```sh
python3 -m http.server 8000
```

Puis visite `http://localhost:8000`.

## Objectif

Récupère **12 éclats** en moins de 60 secondes. Évite les météores : après trois impacts, la mission est terminée. Le meilleur score est conservé dans le navigateur.

## Commandes

- **Flèches** ou **ZQSD** : déplacer le vaisseau
- **Espace** ou **Maj** : impulsion / dash (avec recharge)
- **Échap** : pause
- **Écran tactile** : glisser pour piloter, bouton *Impulsion* pour le dash
